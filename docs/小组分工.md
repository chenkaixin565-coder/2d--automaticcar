## 各模块对应实现

| 模块 | 主要文件 | 说明 |
|---|---|---|
| 前端界面 | `frontend/src/App.vue`、`components/*` | 地图、控制面板、规划卡、弹窗 |
| 前端服务层 | `services/remoteService.js`、`simulatedService.js` | WS/REST 与离线仿真 |
| 后端 API | `backend/app/api/rest.py`、`websocket.py` | 接口与状态帧 |
| 仿真引擎 | `backend/app/services/simulation_engine.py` | 唯一状态源 |
| 路径规划 | `backend/app/services/planner.py`、`algorithms/astar.py` | 八邻域 A* 与预算 |
| 巡检 | `backend/app/services/patrol.py` | 多点/单点状态机 |
| 异常检测 | `backend/app/services/anomaly.py` | 规则 + IsolationForest |
| Agent | `backend/app/services/agent.py` | 10 个工具与确认 |
| 部署 | `deploy/Dockerfile`、`.github/workflows/*` | 镜像与 CI |
