## 1. 你反馈的问题 → 原因 → 修法

| # | 你看到的 | 实际原因 | 现在的行为 |
|---|---|---|---|
| 1 | 按「按此路线巡检」后提示"规划路线已取消" | 按钮回调里先 `startPatrol` 再 `cancelPlan()`，取消动作会推一条"路线规划已取消"通知 | 开始巡检在服务端**静默**作废预览，不再发取消通知 |
| 2 | 按「按此路线巡检」变成全图自动巡检 | 代码把 `map.goals` 全部传进去，只把目标点排第一 | 只巡预览的那一个点，提示"已出发前往巡检点 [x, y]，单点任务" |
| 3 | 说"去某个巡检点"不生效，还回"自动巡检" | 只支持坐标，不支持"第 N 号巡检点"；且"巡检点"三字会命中巡检意图 | 支持"去 2 号巡检点 / 规划到第 3 个巡检点"，按序号换算坐标；越界回"当前共 N 个" |
| 4 | 因障碍无法到达时没有清障选择 | 巡检拿不到路径时直接记异常并跳过该点（V1.2 旧策略） | 暂停并弹窗："无法到达巡检点 [x,y]，建议清除 [a,b]"，可清除重试 / 跳过 / 停止；拆一格仍无解才跳过 |
| 5 | 规划路线时提示"不可达"，没有下一步 | `plan_route` 失败只发一条 notice，不返回建议 | 失败时找一处"拆掉它就能通"的格子，预览卡显示「清除 [a,b] 并重新规划」按钮 |
| 6 | 规划路线时一键排障没反应、路线还"穿墙" | ① 一键排障只在 `mode=blocked` 时生效，巡检受阻时 mode 仍是 `patrol`，只会回"当前无阻塞故障"；② 预览画的是"穿障理论最短路径"，执行却是绕行，两边语义不一致 | ① 一键排障覆盖三种场景：手动撞墙（免费）/ 巡检受阻（扣 5%，继续）/ 有预览（按规划批量清障）；② 预览卡给两个明确按钮：「清除 N 处并前往」「绕过障碍直接前往」，所见即所得 |
| 7 | 形象上传后不同步 | 形象只存在浏览器 localStorage，从来不上传服务端 | 新增 `GET/PUT/DELETE /api/v1/robot/avatar`，形象版本随状态帧下发，其他设备发现版本变化自动拉取 |

### 顺手修的

- **前端穿障规划还是四邻域**：V2.3.0 只改了后端八邻域，前端 `routePlanner.js` 仍是四邻域、
  直线代价 1，导致同一条路线在"离线仿真"和"后端服务"下算出的耗电不同。已同步为八邻域 + √2。
- **ML 推理计时用例偶发误报**：跑全量测试时多线程 BLAS 抢核，中位数会顶到 5ms 边缘。
  测试环境固定单线程数值库，断言放宽到 20ms（仍能抓住"每次推理都重训"的回归）。
