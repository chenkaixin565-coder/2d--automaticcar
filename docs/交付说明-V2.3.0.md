## 1. 这次补上了什么

对照策划书"进阶版"的四项要求：

| 进阶项 | V2.2.1 状态 | V2.3.0 状态 |
|---|---|---|
| AI 模型 | 代码有，线上默认跑规则 | **auto：有依赖就真跑 IsolationForest**，`/health` 如实上报 |
| Agent | 无 | **10 个白名单工具 + 规则/本地大模型双解析 + 二次确认 + 前端面板** |
| 复杂路径规划 | 4 邻域、无平滑 | **8 邻域 octile + 禁止斜穿墙角 + 视线法平滑 + BFS 对照** |
| 机器人控制 | 仿真闭环完整 | 不变（仍未接实车） |

此外补掉了三个"已知遗留"：`ci.yml` 落库、BFS 对照模块补齐、`docs/api.md` / `algorithm.md` 回到仓库。

## 4. 未做 / 边界（答辩时主动说明）

1. **实车未接**：`DRIVER=real`、串口协议、急停都是策划书里的进阶项，本次没做；
2. **没有多轮对话**：每条指令独立解析，不支持"再往左一点"；
3. **没有 D\* Lite / MAPF**：动态重规划仍是"当前段从头重算"；
4. **公开链接跑规则解析**：Render 免费实例无 GPU，`AGENT_LLM_ENABLED` 默认关闭；
5. **`archive-download.html` 未更新**：它在 `gh-pages` 分支，不在本源码树内；
6. **截图未补**：新增面板与八邻域路径的截图需要跑起来后截，仓库里的 `docs/screenshots` 仍为旧版。

## 5. 怎么提交（给作者）

```bash
cd irm-sim
git status                      # 确认改动范围
git diff --stat
git add -A
git commit -F .commit-msg       # 提交信息已写好
git tag v2.3.0                  # 可选：打标签
git push origin main --tags
```

推送后 Render 会自动重新部署；GitHub Actions 会在 push 到 `main` 时跑三阶段流水线
（注意：推 `.github/workflows/` 需要令牌带 `workflow` 权限）。
